LBS定位点餐与堂食外卖一体化场景融合
用户打开茶饮点餐小程序后，系统通过uni.getLocation获取经纬度，后端用Haversine公式计算各门店与用户距离，按距离由近及远排序展示门店列表。用户可选择附近门店进入点餐页，也可手动切换城市或搜索门店。门店表建立lat/lng联合索引支持高效附近查询。

堂食场景下每张餐桌生成唯一桌码，用户扫码后进入点餐页并自动绑定桌号。系统支持拼桌点餐和共同点餐两种多人模式。拼桌模式下同桌顾客各自独立点餐下单；共同点餐模式下一桌生成一笔订单，同桌顾客可互相看到点餐内容。下单后订单自动归属该桌，厨房打印机自动出单。

外卖场景下用户选择配送地址后，系统计算配送费和预计送达时间。系统支持商家配送和第三方配送对接，包括达达、蜂鸟即配、顺丰同城等。订单状态从待接单、制作中、待取餐、配送中到已送达全程可追踪，用户在小程序端实时查看骑手位置。

所有订单统一收口到订单中心，通过order_type字段区分堂食和外卖。门店后台可分别查看堂食订单和外卖订单，支持自动接单和手动接单。自动接单模式下顾客下单后系统自动接单并打印小票；手动接单需要店员确认。订单语音提醒功能确保门店不错过任何新订单。

门店可独立设置营业时间、休息状态和接单策略。营业时间内门店正常接收堂食和外卖订单；休息状态下用户可浏览商品但无法下单。系统支持预约订单，用户可指定取餐或送达时间，门店按预约时间安排制作。LBS定位点餐、堂食扫码和外卖配送一体化设计使茶饮连锁系统覆盖全场景点餐需求，统一订单中心和灵活接单策略是保障多场景高效履约的技术核心。
